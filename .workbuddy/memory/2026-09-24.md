## opencode.pjgg2023.eu.org 加载慢诊断（17:31-17:45，与 CarLife 无关）

用户报 opencode Web 会话页加载慢。诊断结论（curl 分段计时，账密 Basic Auth 有效）：
- **主因：静态资源零缓存**。① 源站（nginx/opencode serve）响应无 `Cache-Control`/`ETag`/`Last-Modified`
  → 浏览器每次访问都全量重下 2.74MB 主 JS 包；② Basic Auth 的 Authorization 头导致
  Cloudflare 边缘缓存 `cf-cache-status: BYPASS`，每次回源。
- **次因：链路差**。系统代理 127.0.0.1（出口美国，CF-RAY=LAX）：每条新连接 TLS ~1s、请求基线 ~1.3s，
  且随机 TLS 握手失败率 ~20%（观测 2/10 次，一次挂 52s）→ 浏览器重试更慢；直连 Cloudflare 更糟
  （TCP 握手 7.75s，丢包严重）；IPv6 完全不通。
- **排除项**：后端 API 快（/config 1.5s、/session 1.5s、/session/:id/message 181KB 1.8s，
  TLS 后首字节仅 ~0.3s），服务器无问题；压缩正常（zstd/gzip 已启用）。
- **修复建议**：① nginx 给 `/assets/`（文件名带 hash）加 `Cache-Control: public, max-age=31536000, immutable`
  ② CF Cache Rule：`/assets/*` 强制 Eligible for cache + Edge TTL 长缓存（绕过 Authorization 的 BYPASS）
  ③ 换稳定代理节点。
- 诊断材料留档 `C:/PJGG/apk/_opencode_diag/`（curl.cfg 含明文账密，注意）。
