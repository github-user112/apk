  （**Manifest 静态注册**，进程被杀也接得住）。
- 隐藏 API 缺失只记日志不抛；EXTRA_DEVICE 用字面量串（stub android.jar 无该常量）。
- 主界面新增分区「直连免打扰」+ 开启/关闭 + 状态行（累计次数/最近设备），onResume 刷新。
