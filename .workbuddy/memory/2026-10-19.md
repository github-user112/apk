## 排查「没有静音规则，每次启动还是会静音」（BootTask v1.6.35）
- **结论：开机静音有两条互相独立的链，删规则只断一条。**
  1. **规则链**：BootReceiver(smali) → ExecService 扫 prefs `rules` 的 `list` 键 → event=boot + enabled 的规则 → delay 后 action=mute → `MuteGuard.mute + MediaMute.muteAll`。点过「开机静音选择器→保存」就会 `addRule("boot",15,"mute")`，**一个软件都不勾也会加**。v1.6.34 首页瘦身后规则列表只在工具箱二级页，首页看不见 → 造成「没有静音规则」错觉。
  2. **拦截目标链（与规则无关，删规则不断它）**：BootAudioReceiver 每次开机无条件拉起 AudioMonitor → 读 prefs `audiomon` 的 `blockPkgs`（旧键 blockPkg 兜底）→ 目标存活每 5s 杀一次 → 免 root `killBackgroundProcesses` 杀不了前台（MuMu 实测 Permission denied）→ **sAliveTicks>=2（约 10 秒）自动 `MuteGuard.mute()` 全流静音 + 3 分钟看门狗把音量压回 0**。
- **MuMu 实锤**：rules.xml 里就有 `[{action:mute,enabled:true,event:boot,delay:15}]`；audiomon.xml 里 `blockPkgs=com.baidu.carlifevehicle`；audio_monitor.txt 有「目标存活 → force-stop (Permission denied)」。
- **现有关闭路径**：工具箱 →「取消开机静音（含关软件拦截）」= removeMuteRules() + clearBlockTarget()，一键断两条链。只删规则列表不清拦截目标。

## 车机日志实锤（boottask-logs (5)/(6).zip，10-17）+ v1.6.36 修复
- **开机静音真因 = 残留状态，不是开机行为**：车机 10-17 三轮开机（11:34/11:40/11:42）日志里 `ExecService rules=1` 只执行了 `launched net.easyconn`，rules 全库就 `[{"action":"open","pkg":"net.easyconn",...}]`，**没有任何 mute 规则**、拦截目标=无、无 MuteGuard 动作。真正元凶是 10:46 那次把 `android.process.media`（常驻进程，免 root 永远杀不掉）设成拦截目标 → 触发静音兜底 → **MuteGuard 看门狗到期只注销广播、不恢复音量**，而 `setStreamVolume(0)` 会被系统持久化 → 之后每次开机都是 0 音量。
- **v1.6.36 修复（vc43）**：① `MuteGuard.muteTemp()` 临时静音（拦截兜底用），看门狗到期**自动 restore 音量**；`mute()`（smali ExecService 规则链调用）保持长期静音语义不变 ② prefs `muteguard` 记 `tempActive`+`savedVols`，`BootAudioReceiver` 开机调 `restoreIfPending()` 自愈（上次临时静音未到期就重启的场景）③ `applyAll` 首采快照改 `sSavedVolumes==null` 才采样（否则每 5s 重施会把 0 存成原始值）④ 工具箱「取消开机静音」顺带 `MuteGuard.unmute + MediaMute.unmuteAll` 恢复音量（治存量）⑤ `isPickable` 排除 `android.process.media`。
- **MuMu 实测**：临时静音触发后停止重施 → 3 分钟到期日志 `MuteGuard watchdog expired, temp mute auto-restored ... guarded=false`，music 0/15→7/15（saved 全 0 时回退 max/2）、prefs 标志自动清空。
- MuMu 坑：**`adb reboot` 常不设 `sys.boot_completed` → BOOT_COMPLETED 不投递**（本次只有 09:39 那轮收到，且延迟 ~102s）；shell/root 的 `am broadcast -a ...BOOT_COMPLETED` 都送不到受保护广播（result=0 但无接收器）；adb push 本地路径必须用 Windows 格式 `C:/...`；bash 里 `UID` 是只读变量，别用它存 uid。
