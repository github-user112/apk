## v1.6.78（vc94）：无障碍升级自愈（MuMu 无法验证，车机应有效）
- **实测发现**：pm install -r 覆盖安装后，4.4 系统会把被替换包的无障碍服务从 enabled_accessibility_services 摘掉（用户开关还在、服务悄悄失效）。
- P2pAutoAccept.ensureServiceOn：开关开且系统里无服务时，经 AdbBridge（adbd root 通道）settings put 补回（保留其他已启用服务），接入 ToolboxActivity.onResume。异步幂等。
- **MuMu 验证失败原因 = 环境限制**：MuMu ro.adb.secure=1 且无 adb_keys，App 的 RSA 公钥没授权 → AUTH 拒 → heal abort（日志见 boottask.log）。车机 ro.adb.secure 为空（deploy_final.sh 注释实锤），同通道开热点已验证可用 → 代码保留，真车待验。用户拍板：MuMu 上不折腾了。

### MuMu 测试技巧沉淀
