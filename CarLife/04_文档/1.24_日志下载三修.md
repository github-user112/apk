## 1. bind 失败透出界面（#1）

### 现象 / 根因

`LogHttpServer.start()` 里 `ServerSocket.bind` 抛异常（典型：18080 被占）
原先只打 logcat，界面照常画二维码 → 扫码 `connection refused`。

### 修复（`LogDownloadActivity.onStart`）

```java
LogHttpServer.get().start();
if (!LogHttpServer.get().isRunning() && mHint != null) {
    mHint.setText("端口 " + LogHttpServer.PORT + " 启动失败（可能被占用），请稍后重试");
    mHint.setTextColor(0xFFFF6B6B);
    Log.e(TAG, "server not running after start()");
} else if (mHint != null && mUrls != null) {
    mHint.setText(buildHint(mUrls));
    mHint.setTextColor(FG2);
}
```

- `mHint` / `mUrls` 在 `onCreate` 赋值；`onStart` 检查失败走红字，成功重建原有 hint。
- 不改启停时机（仍是 `onStart` 起 / `onStop` 停，4.4 上 `onDestroy` 不保证）。

## 2. 去掉无网卡时的假二维码（#2）

### 现象 / 根因

`LogHttpServer.localIps()` 在 `ips.isEmpty()` 时无条件塞 `192.168.49.1`（P2P GO 默认网段）。
WiFi 没开 / 无网卡时界面仍画出必然打不开的码，与 `netSummary` 的
「未检测到可用网卡」自相矛盾。

### 修复

- 删除该兜底，空数组交给 `buildHint` 既有分支：
  **「未检测到可用网络地址，请检查 WiFi 连接」**。
- 需要 `p2p0=192.168.49.1` 时由真实枚举得到，不再硬编。

dex 复核：`192.168.49.1` **字面量已消失**；`未检测到可用网络地址` 仍在。

## 3. sendFile Content-Length 与实际发送对齐（#4，保守定长）

### 现象 / 根因

原先头里写 `f.length()`，随后循环读到 EOF。日志轮转（gzip + 删原文件）
期间可能短发/超发 → 客户端卡死或截断。

### 修复（`LogHttpServer.sendFile`，保守版，不引入 chunked）

1. 写头前取死 `final long len = f.length()`，`Content-Length: len`。
2. 发送循环按 `min(buf, len - sent)` 截断，`sent >= len` 即 `break`（防超发）。
3. 日志打 `bytes=sent/len`，便于对账。

**刻意不做**：chunked 编码 / 重开文件重试 —— 需要时再加（`ponytail:`）。

## 4. 合并点门禁补 logxfer（#3）

`verify_dalvik_合并点检查.py` 的 `TARGETS` 从未包含 logxfer 四个 smali ——
D8 产出的手改路径是盲区。已追加 5 条：

- `LogHttpServer.smali` / `LogDownloadActivity.smali` / `LogXferEntry.smali`
- `LogHttpServer$1.smali` / `LogDownloadActivity$BackHandler.smali`

（文件不存在时脚本本就会跳过，对旧树无副作用。）

`校验并补齐工程.py` 的 `EXPECTED_DIFF` 同步登记上述 smali，1.24 的 4 处
内容差（`apktool.yml` + 3 个 logxfer）全部被识别为故意。

## 5. 工具链（本机 Linux aarch64）

`构建日志下载smali.py` 从 Windows 硬编码移植为跨平台：

| 项 | 原 Windows | 现 Linux |
|---|---|---|
| javac/java/javap | `C:\PJGG\...\jdk-17` | `JAVA_HOME` 或 PATH |
| r8.jar | 仓库内（LFS 指针） | `/tmp/opencode/logxfer_tools/r8.jar`（8.3.37） |
| android.jar | 仓库内（LFS 指针） | `/tmp/opencode/logxfer_tools/android-all.jar`（4.4_r1） |
| apktool | `tools/apktool.jar` | `/tmp/opencode/apktools/apktool_qemu.jar` |
| 壳 APK | 1.6 baseline | 同（git-lfs pull 后真实 ZIP，无 logxfer） |

判定规则：文件头必须是 `PK`，LFS 指针（`version https://git-...`）自动跳过。
环境变量 `R8_JAR` / `ANDROID_JAR` / `APKTOOL_JAR` 可覆盖。
